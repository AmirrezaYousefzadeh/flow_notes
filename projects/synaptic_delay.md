## sky130 items (audit of 2026-10-24)

### 1. Hold waivers between gated-clock banks (notes 9.2, 6.1)
- `SpikeDelayNet/HW_simulation/synthesis/common/core.sdc:35,54-57` waives hold between the gated-clock banks and uses
  a hold uncertainty of 0.05 ns. Hold buffers went from 10–14 k (margin 0.8 ns) to 0–41. The waivers rest on a
  protocol argument that gate-level simulation cannot check (timing checks are dropped). Decide with the owner whether
  to re-harden with the paths timed, or document the argument with the results.

### 2. Scratch copy with the clock-stop hook (notes 8.2)
- `sky130-delay-snn/` has the `CLK_STOP_ICG` hook; no log shows it was used, and `HW_simulation/` has none. Remove the
  hook or the scratch copy so it cannot be used by mistake.

### 3. Low-voltage numbers (notes 5.7)
- `HW_RESULTS.md:30-32` compares static energy at 1.8 V / 25 °C with `ss_n40C_1v28` (−40 °C): 218 → 6.9 nJ. State the
  temperature next to the number; part of the 32× is temperature, not voltage.

### 4. Stale memory content
- Done by the maintainer on 2026-10-24 (memory note updated).

### 5. Worth sharing
- `sim/sdf_fast.patch` / `tools/sdf_fast.vpi` (fast `$sdf_annotate`) is now referenced in the shared notes (7.4).
  Keep it in the repository with a short README on how to build it.

## ASAP7 (clone sky130-snn-bmi) items (audit of 2026-10-24)

This folder is a clone of `/media/amir/BCI_paper` at the same commit (`cc819ec`), and its ASAP7 scripts are
byte-identical. The issues found in them are listed in the ASAP7 section of `/media/amir/flow_notes/projects/BCI_paper.md` and will be fixed
there. Before you reuse any ASAP7 script or number from this clone, read that file and
`/media/amir/flow_notes/ASAP7_flow_notes.md`. In short: per-cell leakage in `sw/asap7_leakage.py` is halved, ORFS ran at the FF
corner, annotated Icarus delays are rounded to 10 ps, and hold is not checked by the acceptance script.

This item closes once the clone has been updated from BCI_paper, or if this project no longer uses ASAP7.
