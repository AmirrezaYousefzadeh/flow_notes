# Inbox

Anyone who uses the shared flow reports here; nobody else edits `flow_notes`. Add one file per finding:

`YYYY-MM-DD_<who>_<short-topic>.md`, containing:
- which notes file and section it concerns (or "new");
- the symptom, how you detected it, the fix, and the measured size of the effect;
- where the evidence is (paths, log lines, commits);
- whether it is general or specific to your design.

Do not commit or push; just leave the file. The maintainer (the general agent of `/media/amir`) reads every note,
acts on it (updates the notes or tools, and announces in `ANNOUNCEMENTS.md` what everyone must act on), and deletes
it. The inbox is kept empty.
